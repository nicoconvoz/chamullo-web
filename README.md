# chamullo-web

Download page for the CHAMULLO Android app, served with GitHub Pages at https://nicoconvoz.github.io/chamullo-web/.

- `chamullo-android.apk`: the latest build.
- `version.txt`: the version of that build. The app reads it to show the "new version" notice.

Published from the main repository with `scripts/publish-web.sh` (https://github.com/nicoconvoz/CHAMULLO).
